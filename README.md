# Medical-VQA
Medical Visual Question Answering (Med-VQA): A Comparative Analysis of Baseline and Transformer-Based Architectures 
This project presents a comparative analysis of baseline and transformer-based architectures for **Medical Visual Question Answering (Med-VQA)** using the **VQA-RAD** dataset. The study evaluates the performance of a traditional **CNN–LSTM** baseline model and a state-of-the-art **BLIP** transformer-based model on medical image–question pairs.
## 📌 Project Overview
Medical Visual Question Answering aims to automatically answer natural language questions related to medical images. Due to the complexity of medical data and limited dataset size, this task remains challenging. In this project, two different modeling approaches are explored:
- A **CNN–LSTM** model trained from scratch as a baseline.
- A **BLIP** model that leverages large-scale pre-training and multimodal transformers.
## 🧠 Models Used
- **BASELINE CNN +LSTM MODEL**  
  Combines convolutional neural networks for image feature extraction with LSTM networks for question encoding.

- **ADVANCED BLIP VISION–LANGUAGE MODEL**  
  A transformer-based multimodal model pre-trained on large image–text datasets and fine-tuned on the medical VQA task.
## 📊 Dataset
- **VQA-RAD Dataset**  
  A medical visual question answering dataset consisting of radiology images paired with clinical questions and answers.
